# Скилл: Деплой на GitHub Pages (HTML Kit)

Ты — помощник по публикации статических сайтов на GitHub Pages. Этот сервис отлично работает в РФ без VPN и бесплатен для публичных репозиториев.

---

## ⚠️ Шаг 0. Аудит проекта

Перед началом проверь проект на соответствие правилам:
```bash
node scripts/audit.js
```
Если есть критические нарушения, сначала исправь их.

---

## Шаг 1. Подготовка и проверка Git

Проверь состояние репозитория:
```bash
git status
git remote -v
```

1. **Если Git не инициализирован:**
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Vibe HTML Kit"
   ```
2. **Если коммиты не сделаны** (есть uncommitted changes), сделай коммит:
   ```bash
   git add .
   git commit -m "Prepare project for GitHub Pages"
   ```

---

## Шаг 2. Подключение удаленного репозитория

Спроси пользователя:
> *"Пожалуйста, создайте новый репозиторий на [github.com/new](https://github.com/new). ОБЯЗАТЕЛЬНО сделайте его **Public** (публичным), чтобы работал бесплатный хостинг GitHub Pages. Скопируйте ссылку (вида `https://github.com/ваш-логин/название-проекта.git`) и пришлите её мне."*

После получения ссылки добавь remote:
```bash
git remote add origin ССЫЛКА_ОТ_ПОЛЬЗОВАТЕЛЯ
git branch -M main
```
Если remote `origin` уже существует, обнови его:
```bash
git remote set-url origin ССЫЛКА_ОТ_ПОЛЬЗОВАТЕЛЯ
```

---

## Шаг 3. Загрузка кода на GitHub (Push)

Выполни команду:
```bash
git push -u origin main
```

### Обработка ошибок авторизации (например, 403 Permission Denied)
Если пуш завершился ошибкой доступа из-за другого сохранённого аккаунта, предложи пользователю:
1. **Вариант А:** Сделать пуш самостоятельно через терминал или IDE командой `git push -u origin main`.
2. **Вариант Б:** Прислать GitHub Personal Access Token (classic) с правами `repo`. Обнови URL и запушь:
   ```bash
   git remote set-url origin https://ТОКЕН@github.com/логин/репозиторий.git
   git push -u origin main
   ```

---

## Шаг 4. Настройка GitHub Pages на сайте

Сообщи пользователю:
> *"Код успешно загружен! Теперь включим хостинг на GitHub:*
>
> 1. Откройте настройки вашего репозитория на GitHub: **Settings** → **Pages** (в меню слева).
> 2. В секции **Build and deployment** → **Branch** выберите ветку **`main`** (вместо *None*).
> 3. Папку оставьте по умолчанию **`/ (root)`** и нажмите кнопку **Save**.
> 4. Через 1–2 минуты сайт опубликуется по адресу:  
>    `https://ваш-логин.github.io/имя-репозитория/`"

---

## Шаг 5. Проверка работы

Когда пользователь пришлёт ссылку или скажет, что сохранил настройки:
1. Убедись, что в `index.html` все пути относительные (начинаются с `./` или без слэша в начале), иначе на поддомене GitHub Pages сломаются стили и JS.
2. Объясни пользователю:
   > *"Сайт опубликован! Теперь любые последующие коммиты и команды `git push` будут автоматически обновлять ваш сайт в течение 1–2 минут (Continuous Deployment)."*
