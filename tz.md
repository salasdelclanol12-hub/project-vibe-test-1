2. Симулятор "Баланс семейных ресурсов" (Drag & Drop или Слайдеры)
Суть: Пользователю дается условные "100 единиц энергии" на неделю. Он должен распределить их по сферам: "Работа", "Время с партнером", "Время с детьми", "Личное время (Я)", "Быт".
Геймификация:
Если пользователь ставит "Личное время" на 0%, появляется забавное, но мягкое предупреждение от "внутреннего психолога": "Осторожно! Батарейка на нуле, риск выгорания 99%".
Визуализация в виде динамической круговой диаграммы или стека блоков, которые перестраиваются в реальном времени.
Реализация (Стек):
JS: Обработчики событий input на <input type="range">. Логика проверки суммы значений (должна быть равна 100). Динамическое обновление CSS-переменных для ширины/высоты блоков.
Стили: Vanilla CSS переменные (--work-width: 30%), которые применяются к Tailwind-классам через inline-стили (style="width: var(--work-width)"). Анимация появления предупреждений через @keyframes.
Точка захвата: "Ваш баланс несбалансирован. Оставьте email, чтобы получить чек-лист 'Как найти 30 минут для себя, не вызывая чувства вины'".
